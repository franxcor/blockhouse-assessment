#  State Management Details

## Framework : React

For this assessment, I chose to use React, in part because it is a language that is familar to me, but also that it has a lot of useful functions that work very well with API integration. 

### Familiarity
Because I have worked on multiple projects that involve React and Javascript, it was an easy choice. Not only did I have previous resources and code that I could reference, but because it is also a popular language, there was a lot of help and documentation that I could refer to if I got stuck.

### useState & useEffect
I think react's useState and useEffect were particularly useful to me during this project. I used state variables a lot throughout this project, both for data management, but also for displaying certain information so that the page wasn't too crowded. Furthermore, useEffect helped me to load the information when the page loaded so that people didn't have to manually load it, which I believe helped a bit with UX.
